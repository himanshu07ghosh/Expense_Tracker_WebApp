## 💰 Expense Tracker Web App

A simple, interactive, and responsive Expense Tracker Web Application to manage and monitor monthly expenses efficiently.
Built using HTML, CSS, and JavaScript, this app allows users to record daily spending, filter expenses by month, view recent transactions, and track total expenditure with a clean UI and dark mode support.

## 📌 Features & Functionality
- ✅ Add Expenses
- Enter item name, amount, and date
- Validation to ensure all fields are filled
- Expenses are added instantly using the Add Expense button


## 📅 Monthly Filter

- Filter expenses by month (Jan–Dec)
- Displays only selected month’s transactions

# Automatically updates:
- Total amount spent
- Number of entries
- Transaction list


## 📋 Recent Transactions

# Displays expenses in a structured table format:
- Date
- Item Name
- Amount (₹)
- Delete option
- Proper column alignment for better readability
- Individual expenses can be deleted using the trash icon


## 💵 Total Spent Summary

- Displays the total amount spent for the selected month
- Shows total number of expense entries
- Amount formatted in Indian number system
- Example: ₹12,34,28,309.00


## 🌗 Dark Mode

- Toggle between Light Mode and Dark Mode
- User theme preference is saved using LocalStorage
- Automatically applied on page reload


## 💾 Persistent Storage

- Uses Browser LocalStorage
- Expenses remain saved even after refreshing or reopening the browser


## 📱 Responsive Design

- Fully responsive layout

# Works smoothly on:

- Desktop

- Tablet

- Mobile devices
